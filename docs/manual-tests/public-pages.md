# คู่มือทดสอบด้วยมือ — หน้าสาธารณะ

ส่วนที่เป็นตรรกะมี unit test คลุมแล้ว (`lib/help/docAssets.test.ts`)
เอกสารนี้คือส่วนที่ต้องใช้ตาดู

## A. เข้าถึงได้โดยไม่ล็อกอิน

เปิดหน้าต่างไม่ระบุตัวตน แล้วเปิด `/` และ `/help`

**ผลที่ต้องได้:** เห็นทั้งสองหน้า ไม่ถูกเด้งไป `/login`

ถ้าถูกเด้ง แปลว่ามีคนเพิ่มเส้นทางเข้า `matcher` ใน `middleware.ts` — เอาออก

## B. ไม่เด้งผู้ใช้ที่ล็อกอินแล้ว

ล็อกอินแล้วเปิด `/`

**ผลที่ต้องได้:** ยังเห็นหน้าแนะนำ และปุ่มขวาบนเป็น "ไปที่ Dashboard"

ของเดิม `app/page.tsx` เด้งไป `/dashboard` ทันที ทำให้ดูหน้าแรกของตัวเองไม่ได้เลย

## C. ไฟล์ PDF

กด "ดาวน์โหลด PDF" และ "เปิดในแท็บใหม่" ที่หน้า `/help`

**ผลที่ต้องได้:** ไฟล์เปิดได้ · ภาษาไทยเป็นตัวอักษรจริงไม่ใช่สี่เหลี่ยม ·
สระบนและวรรณยุกต์อยู่ตำแหน่งถูก ไม่ลอยหรือทับกัน ·
เวอร์ชันบนหน้าปกตรงกับที่แสดงข้างปุ่ม

## D. บนมือถือ

เปิดทั้งสองหน้าบนจอกว้าง 375px

**ผลที่ต้องได้:** อ่านได้ ไม่มีข้อความล้นขอบ ตาราง UAT เลื่อนแนวนอนได้

## E. หลัง deploy

เปิดหน้า `/help` บนโปรดักชันแล้วกดดาวน์โหลด

**ผลที่ต้องได้:** ไม่ใช่ 404

ข้อนี้ดักการลืม commit ไฟล์ PDF ซึ่งบนเครื่องตัวเองจะไม่มีทางเห็น เพราะไฟล์
ยังอยู่ในโฟลเดอร์ `public/` ของเครื่องนั้น

## F. ความตรงกันของเนื้อหาสองชุด

เทียบหัวข้อในคู่มือบนหน้าเว็บกับในไฟล์ PDF

**ผลที่ต้องได้:** ตรงกัน — ถ้าไม่ตรง แปลว่ามีคนแก้ที่เดียวแล้วลืมอีกที่
ให้ดูหัวข้อ "หน้าสาธารณะ" ใน CLAUDE.md ว่าต้องแก้ที่ไหนบ้าง

## ส่วนที่ 1 — คู่มือการใช้งาน

### 1.1 เข้าสู่ระบบและสมัครสมาชิก

1. เปิดหน้าแรกแล้วกด "เข้าสู่ระบบ" ที่มุมขวาบน
2. ผู้ใช้ใหม่กด "สมัครสมาชิก" กรอกอีเมลและรหัสผ่าน ระบบจะส่งลิงก์ยืนยันไปที่อีเมล
3. กดลิงก์ในอีเมลแล้วระบบจะพาเข้าสู่ Dashboard ให้อัตโนมัติ ไม่ต้องล็อกอินซ้ำ
4. ลืมรหัสผ่านให้กด "ลืมรหัสผ่าน" ที่หน้าเข้าสู่ระบบ ระบบจะส่งลิงก์ตั้งรหัสใหม่ไปให้

### 1.2 Dashboard

1. แสดงจำนวนผู้สมัครทั้งหมด ยอดเปลี่ยนแปลงใน 30 วัน และจำนวนตำแหน่งงานที่เปิด
2. ยอดเปลี่ยนแปลงเป็นสุทธิ คือคนที่เข้ามาใหม่ลบด้วยคนที่ถูกลบ — เขียวมีเครื่องหมายบวกคือเพิ่มขึ้น แดงมีเครื่องหมายลบคือลดลง
3. ส่วน Shortlist แสดงเฉพาะรายการของคุณเอง คนอื่นมองไม่เห็น
4. ส่วน "เพิ่งดูล่าสุด" และ "กิจกรรมของคุณ" แสดงเฉพาะสิ่งที่คุณทำ ไม่ใช่ของทั้งระบบ

### 1.3 ค้นหาผู้สมัคร

1. พิมพ์สิ่งที่ต้องการเป็นประโยคภาษาไทย เช่น "หา Data Scientist จบโทอเมริกา ประสบการณ์ 5 ปีขึ้นไป"
2. กด Enter หรือปุ่มค้นหา
3. ระบบแยกประโยคเป็นเงื่อนไขแล้วแสดงเป็นชิปด้านบน กดชิปเพื่อปิดเงื่อนไขนั้นได้
4. ผลลัพธ์เรียงตามความใกล้เคียงเชิงความหมาย คะแนนเป็นตัวเลข 0–100
5. กดชื่อผู้สมัครเพื่อดูรายละเอียดเต็ม

### 1.4 หน้าผู้สมัคร

1. ส่วนบนแสดงชื่อ ตำแหน่งย่อ สถานที่ และลิงก์ไปโปรไฟล์ LinkedIn ถ้ามี
2. ไทม์ไลน์แสดงประวัติการศึกษาและการทำงานเรียงตามเวลา
3. ส่วน "วิเคราะห์" ให้พิมพ์ความต้องการแล้วกดวิเคราะห์ ระบบให้คะแนนพร้อมเหตุผลภาษาไทย
4. ผลวิเคราะห์ถูกเก็บไว้ ถ้าถามด้วยข้อความเดิมอีกครั้งจะได้ผลเดิมทันทีโดยไม่เรียก AI ซ้ำ
5. ส่วน "เพิ่มเข้า Shortlist" เลือกรายการที่มีอยู่หรือสร้างใหม่ได้ในที่เดียว

### 1.5 Shortlist

1. Shortlist เป็นของส่วนตัว คนอื่นมองไม่เห็นรายการของคุณ
2. สร้างรายการใหม่ได้จากหน้า Shortlist หรือจากหน้าผู้สมัครโดยตรง
3. เอาผู้สมัครออกจากรายการได้จากหน้า Shortlist โดยผู้สมัครยังอยู่ในฐานข้อมูลตามเดิม

### 1.6 ตำแหน่งงาน

1. กด "สร้างตำแหน่งงาน" แล้วกรอกชื่อตำแหน่ง คำอธิบาย ทักษะที่ต้องการ และประสบการณ์ขั้นต่ำ
2. เปิดตำแหน่งงานที่สร้างแล้วจะเห็นรายชื่อผู้สมัครที่เหมาะที่สุดเรียงให้อัตโนมัติ
3. การจัดอันดับนี้ไม่เรียก AI จึงเร็วและไม่มีค่าใช้จ่าย
4. กด "วิเคราะห์เชิงลึก" ที่ผู้สมัครรายคนเมื่อต้องการคะแนนพร้อมเหตุผล

### 1.7 ประเมินตัวเอง

1. อัปโหลดไฟล์เรซูเม่ของตัวเองเป็น PDF
2. ระบบอ่านไฟล์แล้วสรุปข้อมูลออกมาให้ตรวจ
3. ระบบจัดอันดับตำแหน่งงานในระบบที่เหมาะกับคุณที่สุด
4. ข้อมูลส่วนนี้เก็บแยกคนละตารางกับฐานผู้สมัคร ผู้สรรหาค้นหาไม่เจอ

### 1.8 จัดการข้อมูล (เฉพาะ data manager ขึ้นไป)

1. หน้า "ข้อมูล" แสดงผู้สมัครทั้งหมดในตาราง เรียง ค้นหา และแบ่งหน้าได้
2. ปุ่ม "แสดงเฉพาะที่มีปัญหา" กรองเฉพาะแถวที่ข้อมูลไม่ครบหรือชื่อซ้ำ
3. ติ๊กเลือกหลายแถวแล้วกด "ลบที่เลือก" เพื่อลบเป็นกลุ่ม
4. กล่องยืนยันจะเตือนถ้ามีคนที่มาจากการนำเข้าอัตโนมัติ เพราะลบเฉยๆ แล้วรอบถัดไปจะกลับมา
5. ติ๊ก "ห้ามนำเข้าอีก" เมื่อต้องการกันไม่ให้กลับมา ระบบจะจำไว้ถาวร
6. ส่วน "บันทึกกิจกรรม" ท้ายหน้าแสดงการเปลี่ยนแปลงของทุกคนในระบบ
7. หน้า "Import" ใช้วางไฟล์ CSV เอง และดูคิวรอตรวจกับรายชื่อที่ถูกระงับ

### 1.9 ตั้งค่า

1. เปลี่ยนชื่อที่แสดงและรหัสผ่านได้ที่หน้าตั้งค่า
2. การเปลี่ยนรหัสผ่านต้องกรอกรหัสผ่านเดิมเพื่อยืนยันตัวตนก่อน
